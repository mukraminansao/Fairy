# FAIRY usability review

- [Desktop homepage](desktop-homepage.png), [fashion scene](desktop-fashion.png), [makeup scene](desktop-makeup.png), and [Beauty Studio](desktop-studio.png). Chrome, 1672 × 941, device pixel ratio 1.
- [Phone homepage](mobile-homepage.png), [menu](mobile-menu.png), and [search](mobile-search.png). Chrome, 390 × 844.

The desktop header keeps its height and navigation arrangement. The comparison overlays show the existing differences in photography and the extra set pickers on the fashion and makeup scenes. The mobile menu and search are new designs for this review. Their actions use the same colors and type as the desktop header.

The homepage fit at 320, 390, 768, 1211, 1440, and 1672 px in Chrome. At 390 px, the campaign image transfer fell from 234,578 to 28,402 bytes in local browser checks. At 1672 px it fell to 65,440 bytes. These figures measure the hero image only.

Keyboard checks covered opening the menu, closing it with Escape, and returning focus to the trigger. The phone preview also passed backdrop dismissal and search without a full reload. The local production rehearsal passed seeded catalog, guest checkout, and mobile studio checks.
