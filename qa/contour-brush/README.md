# Contour brush review

- [Desktop model, 1672 × 941](fairy-contour-desktop.png)
- [Touch preview, 390 × 844](fairy-contour-mobile.png)
- [Selfie comparison, 1672 × 941](fairy-contour-selfie.png)

Compared with the supplied Virtual Beauty Studio reference. The three desktop columns and original sample crop are retained in the default studio. The brush adds tools directly above the preview and reveals more of the sample forehead and jaw so both are reachable. A full-height face can extend below the fold while these tools are open.

Verified mouse, keyboard, touch, zoom, undo, clearing, blending, saving the sample look, and 768px tablet width. The selfie test used the supplied model photo as a local upload and verified that the original stays unchanged, that the after view includes the strokes, and that those strokes are discarded with the photo. The camera capture check used a simulated camera feed.
