# FAIRY beauty expansion

The Beauty Studio and set browser now support six beauty collections. Three new collections add 36 distinct products; each product has an original image-space hotspot and a separate, editorial close-up.

- [Peach Atelier](peach-atelier-scene.png)
- [Mocha Sculpt](mocha-sculpt-scene.png)
- [Midnight Pearl](midnight-pearl-scene.png)
- [Mixed beauty look and contour palette](fairy-six-set-studio.png)
- [Camera shot in the still comparison editor](fairy-camera-capture.png)
- [Contour placement on a local selfie](fairy-contour-placement.png)

The desktop captures are 1672 × 941. The new collections follow the approved Soft Rose Edit structure: a shoppable photo, selected item outline and connector, dedicated close-up, and a preview of the current beauty look. They have no separate design reference image. Each of the 36 new products was clicked on its scene photo and verified to show its own close-up.

The shot was captured from a simulated webcam using the supplied FAIRY sample. A shot remains local and uses the original camera frame, so the before/after slider can reveal the unedited side. The webcam track stops when the photo opens.
