# FAIRY visual assets

- `references/`: approved complete **FAIRY** website screenshots (visual targets only, never shipped as webpage backgrounds).
- `images/`: clean standalone production-usable editorial photos and 2D model/mannequin placeholders.
- `original/`: user's original product flat-lay used for *direct-click shoppable imagery*; do not crop it on the detailed fashion scene.
- `brand/`: optional wordmark SVG; match the reference with actual webfont-based text if more faithful.

All app-owned cosmetics branding in generated images is **FAIRY**. The original streetwear photo contains unrelated clothing/product marks; that photo is preserved per user request.

Map files according to `docs/05_ASSETS_AND_PROVENANCE.md` and `data/catalog.json` / `data/scenes.json`. All object selections should be independent accessible controls over the actual photographs. No screenshot wallpaper, no fake 3D claim, no self-image upload without opt-in.
